Obsidian 官网柔和浅色用户样式。
A soft light userstyle for the Obsidian website, featuring a light gray canvas, white surfaces, dark text, and muted lavender accents.

## 简介 / About

为喜欢浅色界面的用户提供一套柔和的 Obsidian 官网配色：

- 浅灰色页面背景，减少大面积纯白。
- 白色搜索框、表单与内容区域。
- 深色文字与单色界面图标。
- 柔和的薰衣草紫强调色。
- 保留网站原有布局及彩色图片，并对相关界面元素进行浅色适配。

这是非官方的浏览器用户样式，不是 Obsidian 应用内部主题。

This is an unofficial website userstyle, not an Obsidian app theme. It is not affiliated with or endorsed by Obsidian.

## 安装 / Installation

### 使用 Stylus

1. 安装并启用 Stylus 扩展。
2. 在本仓库中打开 `obsidian-soft-light.user.css`。
3. 点击 `Raw` 打开原始文件。
4. 在 Stylus 安装页面中确认安装。
5. 打开或刷新 Obsidian 官网。

在不支持 UserCSS 自动安装的工具中，可尝试手动导入；具体操作取决于所使用的样式管理工具。

### Install with Stylus

1. Install and enable Stylus.
2. Open `obsidian-soft-light.user.css` in this repository.
3. Click `Raw`.
4. Confirm installation in Stylus.
5. Open or refresh the Obsidian website.

## 自定义颜色 / Colors

主要颜色：

| 用途 | 颜色 |
| --- | --- |
| 页面背景 / Canvas | `#f5f5f5` |
| 白色区域 / White surfaces | `#ffffff` |
| 正文 / Primary text | `#161616` |
| 次要文字 / Muted text | `#505050` |
| 强调色 / Accent | `#7b6cd9` |
| 强调色悬停 / Accent hover | `#6a5bc7` |
| 危险操作 / Danger | `#df7676` |

修改时请注意区分背景、文字及图标颜色，不建议对所有颜色进行无差别替换。

## 问题反馈 / Issues

如果发现文字难以阅读、残留深色背景或其他显示问题，请提交 Issue，并尽量提供：

- 页面地址；请移除敏感参数。
- 浏览器名称与版本。
- 设备或操作系统。
- 问题截图。
- 使用的样式版本。

请勿在截图或反馈中包含密码、API Key、付款信息或其他私人数据。
